# 🤖 AI Chatbot using Groq & LLaMA 3.3 70B

A beginner friendly AI chatbot built with Groq API and Meta's LLaMA 3.3 70B model running directly in Google Colab!

---

## 🚀 Features

- Ask anything and get instant AI-powered responses
- Uses LLaMA 3.3 70B one of the most powerful open source models
- 100% free to use with Groq's free tier
- No setup required runs directly in Google Colab

---

## 🛠️ Tech Stack

- [Groq API](https://console.groq.com) ultra-fast AI inference
- LLaMA 3.3 70B by Meta
- Python
- Google Colab

---

## ⚡ Quick Start

1. Open the notebook in Google Colab
2. Get your free API key from 👉 [console.groq.com](https://console.groq.com)
3. Add it to Colab Secrets as `Groq_Api_Key`
4. Run all cells and start chatting!

---

## 🔑 How to Get Groq API Key

1. Go to [https://console.groq.com](https://console.groq.com)
2. Sign up for a free account
3. Click **"API Keys"** from the left sidebar
4. Click **"Create API Key"** and copy it
